## 2. VOCA TEST 문제지 (1쪽) 레이아웃

페이지: A4 세로(595 × 842pt). 전체를 얇은 회색 테두리(둥근 모서리) 카드가 감싸고, 카드 아래 중앙에 작은 회색 푸터 텍스트.

```
┌──────────────────────────────────────────────────────────────┐
│▌SOVS VOCA TEST  중3                         DATE ___________ │  ← 헤더 (왼쪽 진남색 세로 바)
│──────────────────────────────────────────────────────────────│  ← 진남색 밑줄
│ ※ 주어진 영어 단어를 보고 알맞은 우리말 뜻을 쓰시오.   SCORE ____  이름 ____ │
│  1 increase ____________ □  ┆  26 exclude  ____________ □    │
│  2 reduce   ____________ □  ┆  27 compose  ____________ □    │
│  ...                        ┆  ...                           │
│ 25 distribute ___________ □ ┆  50 relate to ___________ □    │
│                                            ★SOVS ENGLISH 로고│
└──────────────────────────────────────────────────────────────┘
                 VOCA TEST(중3) · SOVS ENGLISH
```

### 치수 (pt, 좌상단 원점)
- 카드 여백: 좌우 약 20pt, 상단 약 20pt
- 헤더 제목 "SOVS VOCA TEST": x=39.6, y=30, 글자 높이 약 19pt → Poppins ExtraBold ~16pt, 진남색
- 학년 라벨 "중3": 제목 바로 뒤, 금색(골드), Noto Sans KR Black
- DATE 라벨: x=453, y=33, 소형 Poppins Bold 레터스페이싱, 뒤에 진남색 밑줄
- 지시문: x=28, y=56, Noto Sans KR Medium ~10.5pt
- SCORE / 이름 칸: 지시문 오른쪽 같은 줄 (SCORE x=335, 이름 x=465)
- 단어 리스트: 2단. 왼쪽 단 번호 우측정렬 끝 x≈43, 단어 시작 x=49.3 / 오른쪽 단 번호 끝 x≈326.5, 단어 시작 x=332.5
- 행 간격: **27.75pt** (첫 행 baseline y≈91.4, 25행 → 마지막 y≈757.4)
- 각 행: 번호(진남색 볼드) · 영단어(Poppins SemiBold ~11pt, 검정 #111) · 점선/실선 답란 · 우측 체크 박스(□ 약 9pt, 연회색 테두리)
- 행 구분: 연한 회색 실선(#eeeef2)
- 두 단 사이: 세로 점선(#d0d0d8), x≈ 297~300
- 로고: 우측 하단 (약 x=470~560, y=775~800), `assets/sovs-logo.png`
- 푸터: 카드 밖 중앙, y≈815, 약 7pt 회색 "VOCA TEST(중3) · SOVS ENGLISH"

## 3. VOCA TEST 정답지 (7쪽)

문제지와 동일 골격에 다음이 다름:
- 제목 뒤 라벨: "정답 · 중3" (골드)
- 지시문: "※ 채점용 정답지입니다. 표시는 문제지에 합니다." + 소제목 "구간별 오답 수가 진단 리포트의 어휘 수준 판정에 사용됩니다."
- 이름 칸 없음, SCORE만
- **구간 배지 3개** (가로 한 줄, 각각 좌측 라벨·우측 문항 수):
  - A · 중3 기초 — 15문항 (초록, 1~15번)
  - B · 중3 기본 — 20문항 (파랑, 16~35번)
  - C · 고1 선행 — 15문항 (빨강, 36~50번)
- 각 행: 번호 색이 **구간 색**(초록/파랑/빨강)으로 바뀜, 단어 뒤에 한글 뜻(Noto Sans KR Medium, 작은 크기). 답란·체크박스 없음.
- 뜻 표기 규칙: 품사 다른 뜻은 `;`로, 같은 계열 유의어는 `,`로 구분. 예) `증가하다;증가`, `줄이다,감소시키다`, 숙어는 `…에 참가하다`
- 푸터: "ANSWER KEY(중3) · SOVS ENGLISH"

## 4. 단어 선정 구조 (중3 세트)

| 구간 | 번호 | 수 | 성격 |
|---|---|---|---|
| A 기초 | 1–15 | 15 | 해당 학년 필수 기초 (increase, reduce, discover …) |
| B 기본 | 16–35 | 20 | 해당 학년 핵심 (disappear, severe, crucial, exclude …) |
| C 선행 | 36–50 | 15 | 상위 학년 선행 (devote, sacrifice, conquer, nevertheless …) |

- 난이도는 번호 순으로 상승. 숙어(take part in, relate to)도 포함.
- 품사 혼합(동사 위주, 형용사·명사·부사 일부).

## 5. 고2 세트 제작 시 적용안

- 템플릿 그대로 유지, 변경 항목만 치환: 학년 라벨 `고2`, 푸터 `(고2)`, 구간 라벨
  - A · 고2 기초 (고1 복습 수준) 15문항
  - B · 고2 기본 (수능 기본 어휘) 20문항
  - C · 고3 선행 (수능 고난도/EBS 빈출) 15문항
- 제작 방식: HTML/CSS 템플릿 작성 → Playwright(Chromium)로 A4 PDF 출력 → pypdf로 빈 페이지 삽입·병합. (원본 PDF의 Type 3 폰트와 pypdf Producer 메타가 이 파이프라인을 시사함)
- 데이터는 JSON 한 파일(`{grade, bands:[{label,color,words:[{en,ko}]}]}`)로 두고 문제지·정답지 모두 같은 데이터에서 렌더.
